# ระบบบันทึกข้อมูลการลา (ทดลองใช้)

เว็บแอปบันทึกการลาของบุคลากร ใช้งานผ่านเบราว์เซอร์ ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้ง

## ลองใช้
เปิดหน้า GitHub Pages ของ repo นี้ หรือดาวน์โหลด `index.html` แล้วเปิดด้วย Chrome/Edge

## ส่วนการใช้งาน
- **👤 ยื่นใบลา** (ไม่ต้องเข้าสู่ระบบ) – ผู้ขอลาใส่เลข ID แล้วกรอกประเภท วันที่ เหตุผล ดูประวัติการลาย้อนหลังได้ทุกปีงบประมาณ พิมพ์ใบลา PDF ได้
- **🏢 หัวหน้าส่วนราชการ** – เข้าสู่ระบบด้วยรหัสหน่วยงาน (001–166 ตามทำเนียบ) อนุมัติใบลา ดูรายงานและจัดการบุคลากรเฉพาะหน่วยงานตัวเอง
- **🛡 ผู้ดูแลระบบ** – จัดการข้อมูลทั้งหมด หน่วยงาน วันหยุด แบบฟอร์มใบลา ส่งออก Excel/CSV/PDF

## หมายเหตุ
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage) แต่ละเครื่องแยกกัน ควร “ส่งออกไฟล์ฐานข้อมูล” สำรองไว้เป็นระยะ หรือเชื่อมไฟล์ฐานข้อมูล (.json) บนคอมพิวเตอร์ที่แท็บส่งออก
- หน่วยงานและหัวหน้าส่วนราชการ (เฉพาะระดับจังหวัด) จากทำเนียบหัวหน้าส่วนราชการจังหวัดยะลา ข้อมูล ณ 24 พ.ย. 2569
- การตรวจรหัสผ่านทำในเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์) จึงยังไม่ใช่ระบบรักษาความปลอดภัยเต็มรูปแบบ
- การสร้าง PDF ต้องต่ออินเทอร์เน็ต (โหลด html2canvas/jsPDF จาก cdnjs)
