# ระบบบันทึกข้อมูลการลา (ทดลองใช้)

เว็บแอปบันทึกการลาของบุคลากร ใช้งานผ่านเบราว์เซอร์ ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้ง

## ลองใช้
เปิดหน้า GitHub Pages ของ repo นี้ หรือดาวน์โหลด `index.html` แล้วเปิดด้วย Chrome/Edge

## ส่วนการใช้งาน
- **👤 ยื่นใบลา** – ผู้ขอลาใส่เลข ID แล้วกรอกประเภท วันที่ เหตุผล ดูประวัติการลาย้อนหลังได้ทุกปีงบประมาณ ระบบนับวันทำการ (ไม่นับเสาร์-อาทิตย์/วันหยุด) และพิมพ์ใบลา PDF ได้
- **🛡 ผู้ดูแลข้อมูล** – อนุมัติใบลา, บุคลากร/หน่วยงาน/สายบังคับบัญชา, แบบสรุปวันลา, รายงาน, วันหยุด, แบบฟอร์มใบลา, ส่งออก Excel/CSV/PDF

## หมายเหตุ
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage) แต่ละเครื่องแยกกัน ควร “ส่งออกไฟล์ฐานข้อมูล” สำรองไว้เป็นระยะ หรือเชื่อมไฟล์ฐานข้อมูล (.json) บนคอมพิวเตอร์ที่แท็บส่งออก
- เปิดครั้งแรกจะมีข้อมูลตัวอย่าง (บุคลากรสมมติ) ลบได้ที่แท็บข้อมูลพื้นฐาน
- รายชื่อหน่วยงานระดับจังหวัดยะลาจากแบบ บพ.2 ข้อมูล ณ 1 ก.ย. 2569
- การสร้าง PDF ต้องต่ออินเทอร์เน็ต (โหลด html2canvas/jsPDF จาก cdnjs)
