📡 สถานะ

• ต้องเชื่อมต่อทุกเครื่องที่ใช้บันทึกข้อมูล (เครื่องผู้ดูแล หัวหน้ากลุ่มงาน และเครื่องที่ใช้ยื่นใบลา) เข้าสู่ระบบผู้ดูแลที่เครื่องนั้นแล้ววาง token ครั้งเดียว
• เครื่องที่ไม่ได้เชื่อมต่อ ยังเก็บข้อมูลแยกในเครื่องตามเดิม
• token เก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ได้อยู่ในตัวเว็บ · ห้ามใช้กับเครื่องสาธารณะ
• ทุกการบันทึกจะเก็บประวัติไว้ใน GitHub ย้อนดูหรือกู้คืนได้
